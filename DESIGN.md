# Dashboard design

Mode: Operate. A guided research workbook for beginners and researchers.

Keep the user's blue accent, soft white light mode, near-black dark mode, existing app icon and IBM Plex Sans. Replace the oversized operations banner with a compact heading and a plain-language page guide. Let users expand terminology when needed. Put the selected run and evaluation controls before results, with a clear distinction between evaluation observations and final replay outcomes.

Use one shared 14–16px body/control scale, readable secondary text, restrained borders, and tabular numerals. Reserve monospace for code and identifiers. Use blue for actions and selections. No decorative status lights or artificial live claims. Summary metrics form one quiet strip; tables carry the detailed evidence. Navigation labels and APIs remain compatible.

All four pages must work in both themes and within expanded/collapsed sidebars and mobile layouts. Preserve keyboard-accessible custom selects, visible focus and error/loading states. Guidance must accurately distinguish reference-policy predictions, synthetic results, assumed timing dependence and actual replay costs.
